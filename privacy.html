PRIVACY / WHAT IS RECORDED

Quiet by
design.

Living Uganda is a library, not a platform. It does not ask who you are, and it does not follow you.

Nothing is collected about you

The site sets no cookies, runs no analytics, uses no advertising, and includes no tracking pixels or third-party scripts. There are no accounts, no comments, no newsletter and no forms that send your data anywhere.

Searching the species catalogue happens entirely inside your browser. The catalogue file is downloaded to your device and the matching is done there; the words you type are never sent to a server.

Fonts and images are served from this site itself, so visiting a page does not quietly contact another company.

What the host records

The site is published with GitHub Pages, a service of GitHub, Inc. Like any web host, GitHub records technical information about requests — including IP addresses — in order to deliver the site and to defend it against abuse. Living Uganda does not receive or keep those logs. GitHub's handling of them is described in the GitHub Privacy Statement.

No custom domain is in use at present, so the address you visit is a github.io address operated by GitHub.

Links to other places

Pages link to papers, datasets, photographers and conservation organisations. Those sites have their own privacy practices, and this notice does not cover them.

Corrections and contact

There is no contact form, because a form would mean collecting something. Corrections, image concerns and questions can be raised in the public repository where the site is published: Living Uganda — issues. Anything posted there is public, so please do not include private information.

If you would rather not write in public, the address is arsenebaguma10@gmail.com. It is a personal mailbox; please allow time for a reply.

If you are a rights holder and want an image or a passage reviewed, say so there and it will be looked at.

Changes to this notice

This notice was written on 8 November 2026. If the site later adds something that records visitor activity — for example a mailing list or a statistics service — this page will say so before it goes live.
